คำถามที่พบบ่อย (FAQ)

1. ไม่เก่งคอมพิวเตอร์เลย จะใช้งานยากไหม?

ไม่ยากเลยครับ โปรแกรมออกแบบมาให้มี แถบสีฟ้านำทางด้านบน คอยบอกทีละขั้นว่าต้องกดปุ่มไหนต่อ และมีปุ่ม “ลองเล่นด้วยข้อมูลตัวอย่าง” ให้ทดลองกดคลีนได้ในคลิกเดียวโดยไม่ต้องกลัวทำไฟล์พังครับ

2. โปรแกรมจะเข้าไปแก้ทับไฟล์ Excel ต้นฉบับของฉันไหม?

ไม่แตะไฟล์ต้นฉบับเด็ดขาดครับ โปรแกรมจะอ่านข้อมูลมาแสดงผล และเมื่อคุณกดอนุมัติแล้วส่งออก โปรแกรมจะสร้างเป็นไฟล์ใหม่เสมอ ไฟล์เดิมของคุณจึงปลอดภัย 100%

3. ถ้าตอนสั่งซื้อพิมพ์อีเมลผิด หรือทำ License Key หาย ต้องทำอย่างไร?

ไม่ต้องกังวลครับ! นอกจากรหัสจะแสดงบนหน้าจอเว็บและบันทึกไว้ในเบราว์เซอร์ของคุณทันทีแล้ว หากคุณพิมพ์อีเมลผิด คุณสามารถ กรอกอีเมลใหม่ที่ถูกต้องแล้วอัปโหลดรูปสลิปใบเดิมซ้ำอีกครั้ง ระบบจะออก License Key เดิมของสลิปใบนั้นและส่งเข้าอีเมลใหม่ให้ทันทีครับ

4. ใช้กับคอมพิวเตอร์ระบบไหนได้บ้าง?

รองรับระบบปฏิบัติการ Windows 10 และ Windows 11 (64-bit) โดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ เพิ่มเติมครับ
